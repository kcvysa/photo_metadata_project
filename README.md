# Photo Metadata (Django)

Веб-приложение на Django для работы с метаданными о фотографиях в сети.
Поддерживает импорт/экспорт в форматах **JSON** и **XML**, сохраняет данные
в файлы и дублирует записи в базу данных.

## Возможности

- Ввод метаданных о фотографии через HTML-форму.
- Валидация вводимых данных (длины, диапазоны, формат URL, формат изображения, теги).
- Сохранение записи одновременно:
  - в файл `.json` или `.xml` в папку `media/uploads/`;
  - в базу данных SQLite.
- Загрузка файлов `.json` и `.xml` на сервер с полной проверкой:
  - расширение;
  - размер (максимум 2 МБ);
  - кодировка UTF-8;
  - корректность структуры (обязательные поля, типы, диапазоны).
- Невалидный файл **не сохраняется** на диск (эквивалент удаления).
- Имя файла генерируется автоматически через UUID — оригинальное имя
  от пользователя не используется (защита от path traversal и коллизий).
- Просмотр содержимого всех JSON/XML-файлов из папки `media/uploads/`.
- Просмотр всех записей из базы данных.
- Сообщения об отсутствии файлов и записей.

## Стек

- Python 3.10+
- Django 5.x
- SQLite (встроенная БД)
- XML — стандартная библиотека `xml.etree.ElementTree`
- JSON — стандартная библиотека `json`

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<твой-логин>/photo_metadata_project.git
cd photo_metadata_project

# 2. Создать и активировать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Применить миграции
python manage.py migrate

# 5. (Опционально) создать администратора
python manage.py createsuperuser

# 6. Запустить сервер разработки
python manage.py runserver
